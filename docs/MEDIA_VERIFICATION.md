# Media verification audit

Audit date: 2026-11-17. The application keeps **film/video match**, **uploader identity**, **legal rights**, and **iframe playback** as separate questions. “Matched” means the reviewed source appears to correspond to the catalog title; it does not prove a license grant or that YouTube permits embedding. The app has not manually tested embedding for every ID. Candidate videos are not playable in KADR.

## Playback and thumbnail behavior

- Playable cards and the featured movie open an in-site responsive YouTube iframe and request autoplay. The separate **Ətraflı** action opens the details modal.
- YouTube can refuse autoplay, playback, or embedding based on browser settings, account state, age restrictions, video availability, or uploader settings. KADR shows an external YouTube fallback link for those cases.
- All 24 active thumbnails use `https://i.ytimg.com/vi/{videoId}/hqdefault.jpg`, with locally generated CSS artwork as image-load fallback. Candidate IDs do not show as playable or use candidate thumbnails.
- Embedding has not been manually checked for each video. The user should treat the `embeddingStatus` field as untested until checked in a browser.
